# MiniBlox Alpha 0.0.1

MiniBlox is an open-source TypeScript sandbox map editor and lightweight 3D game creation experiment for the browser.

The goal of MiniBlox is to let creators build, test and play simple 3D maps directly in the browser. The project is designed to be simple enough for beginners to create maps using visual tools, while still being flexible enough for developers to expand it with code and custom gameplay systems in the future.

> ⚠️ MiniBlox is currently in early alpha.
> Some features are incomplete, experimental or still being improved.

## Current Features

- Browser-based 3D map editor
- TypeScript codebase
- Object placement and selection
- Grid and snap tools
- Save and export maps
- Test mode inside the editor
- Basic playable map mode
- Spawn points
- Checkpoints
- Coins
- Damage zones
- Buttons and doors
- Finish goals
- NPC objects
- Basic building blocks and ramps

## Current Development Focus

MiniBlox is currently focused on improving the core creation loop:

1. Create a map
2. Test it inside the editor
3. Save or export it
4. Play the map

The main priorities right now are:

- Fixing gameplay interactions inside editor test mode
- Improving player collision with objects
- Improving grid and snapping tools
- Adding more primitive shapes
- Improving camera controls and mouse aiming
- Making test mode and play mode use the same gameplay logic

## Known Issues

- Some gameplay objects may work in play mode but not correctly in editor test mode.
- Collision handling is still experimental.
- Grid and snapping need more polish.
- The object catalog is still limited.
- Minigame systems are not complete yet.
- Multiplayer and community map sharing are not implemented yet.

## Planned Features

- Better third-person camera controls
- Mouse-based aiming and interaction
- More primitive shapes
- Better collision system
- Improved grid and snapping
- Map templates
- Example maps
- Simple minigame support
- Custom object logic
- TypeScript scripting for advanced creators
- Community map sharing
- Multiplayer support in the future

## Project Vision

MiniBlox is not just a map editor. The long-term vision is to become a small, hackable sandbox game creation platform.

Players should be able to create maps without programming, while developers should be able to extend the engine with custom systems, scripts and gameplay logic.

The project is still very early, but the foundation is being built step by step.

## Installation

Clone the repository:

```bash
git clone https://github.com/xxsamboladiones/Mini-Blox.git
```
```bash
cd Mini-Blox
```
```bash
npm install
```
```bash
npm run dev
```
```bash
npm run build
```
