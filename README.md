# MiniBlox

MiniBlox is an open-source TypeScript sandbox map editor and lightweight 3D game creation platform for the browser.

The project is currently in early alpha and focuses on map creation, object placement, gameplay testing, collision systems and interactive objects.

## Features

- Browser-based 3D map editor
- TypeScript codebase
- Grid and snap tools
- Save and export maps
- Test mode
- Spawn points
- Checkpoints
- Coins
- Damage zones
- Buttons and doors
- Finish goals
- NPC objects

## Status

MiniBlox is in early alpha.
